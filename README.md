# Alauncher

シンプルで高速なウェブサイトランチャー。よく使うサイトをグリッドレイアウトで表示し、検索機能で素早くアクセスできます。
また、自分でカスタマイズして自分だけのランチャーサイトが作れます。

## 特徴

- 🎨 **モダンUI** - クリーンで使いやすいデザイン
- 🌓 **ダークモード対応** - 目に優しいテーマ切り替え
- 🔍 **高速検索** - サイト名とURLで検索可能
- 📱 **レスポンシブ対応** - PC、タブレット、モバイルに対応
- ⚡ **軽量** - 外部ライブラリ不要のピュアJavaScript

## 使い方

1. **フォーク** - このリポジトリをフォークしてください
2. **カスタマイズ** - index.htmlファイルを変更してください
3. **デプロイ** - githubpagesでそのままデプロイできます

## カスタマイズ

`index.html` の `SITES` 配列を編集してサイトを追加・変更できます：

```javascript
const SITES = [
    {
        name: "サイト名",
        url: "https://example.com/",
        icon: "🎯"
    },
    // 追加するサイト...
];
```
